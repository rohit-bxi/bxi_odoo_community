## Module <project_dashboard_odoo>

#### 04.09.2026
#### Version 19.0.3.0.0
#### ADD

- New role based PMO Dashboard with CXO, PMO, Manager and User views. The
  role buttons shown depend on the user's groups; the data itself is always
  filtered by the access level record rules.
- CXO: portfolio health, projects by status, strategic milestones, risk
  heatmap, resource capacity, delayed projects.
- PMO: project health, schedule variance, milestone completion, risk and
  issue tracking, cross project dependencies, resource utilization.
- Manager: team utilization, task progress, overdue tasks, blocked tasks,
  open risks, open issues.
- User: my tasks, my sub-tasks, pending reviews, upcoming due dates, logged
  hours, personal progress.

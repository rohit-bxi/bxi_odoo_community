==================================
Aura Backend Theme - Free Edition
==================================

Aura Backend Theme - Free is a backend UI theme for Odoo 19 that gives the
Odoo shell a cleaner, more branded look without adding heavy customization
overhead.

Features
========

The free module includes:

* Branded sidebar and topbar layout
* Clean login page styling
* Refined list, form, and kanban views
* Polished buttons, badges, alerts, and typography
* Lightweight visual improvements for core backend screens

Installation
============

To install this module:

* Copy the module into your custom addons path
* Restart the Odoo server
* Update the Apps list
* Install ``Aura Backend Theme - Free``

Configuration
=============

After installation, the theme is ready to use. You can still adjust the usual
Odoo company and user settings, but the free edition does not require a theme
configuration panel.

* No extra setup is required for the base look
* The theme is focused on clean defaults and consistent styling

Usage
=====

Once enabled, Aura styles the Odoo backend shell and the core screens used
every day. The free edition is intentionally minimal and keeps the UI focused
on readability and navigation clarity.

# View Customization Scaffold

This folder contains per-view SCSS files for backend view customization.

Use these files to keep styles modular instead of putting everything in one file.

- form_view/form_view.scss: Form view styles
- list_view/list_view.scss: List (tree) view styles
- kanban_view/kanban_view.scss: Kanban view styles
- activity_view/activity_view.scss: Activity view styles
- search_panel/search_panel.scss: Search panel styles
- others/others.scss: Remaining views (pivot, graph, calendar, gantt, map, cohort, etc.)
